# Support

Need help with CircleUp? Here's where to go depending on what you need.

---

## 📖 Documentation

Start with the [README](./README.md) — it covers setup, environment variables, contracts reference, and the API.

---

## 🐛 Found a Bug?

Open a [Bug Report issue](https://github.com/CIRCLEUP-AJO/CIRCLEUP/issues/new?template=bug_report.md).

Please include:
- What you expected vs what happened
- Steps to reproduce
- Your environment (OS, Node version, network)

---

## 💡 Have a Feature Idea?

Open a [Feature Request issue](https://github.com/CIRCLEUP-AJO/CIRCLEUP/issues/new?template=feature_request.md).

---

## 🔐 Found a Security Vulnerability?

**Do not open a public issue.** See [SECURITY.md](./SECURITY.md) for how to report it privately.

---

## 💬 General Questions

For general questions about how CircleUp works, open a [GitHub Discussion](https://github.com/CIRCLEUP-AJO/CIRCLEUP/discussions) or ask in the community.

---

## 🌐 Stellar / Soroban Questions

For questions about Stellar or Soroban specifically:

- [Stellar Developers Docs](https://developers.stellar.org)
- [Stellar Discord](https://discord.gg/stellardev)
- [Soroban Examples](https://soroban.stellar.org/docs)

---

## ⏱ Response Time

This is an open-source project maintained by volunteers. We aim to respond to issues within a few days. Security reports are prioritised — see [SECURITY.md](./SECURITY.md) for the response timeline.
